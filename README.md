## 🚀 Features
- 🤖 **AI-Powered Learning** – Personalized course recommendations for every learner.  
- ⚡ **Next.js Framework** – Fast, modern, and scalable frontend.  
- 🎨 **Customizable Courses** – Adapt learning paths to individual goals.  
- 🌍 **Inclusive Education** – Open access and community-driven.  
- 🔓 **Open-Source Inspired** – Transparency & collaboration at the core.
